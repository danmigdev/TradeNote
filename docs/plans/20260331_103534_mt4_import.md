# Plan: Add MetaTrader 4 (MT4) Native Import

## Context
MT4 exports account history as HTML files. Unlike MT5 (which exports XLSX with individual executions), MT4 HTML reports contain **complete trades** (open + close in one row). Each row must be split into two executions (open and close) for TradeNote's pipeline.

## MT4 HTML Report Structure
- Single HTML file with one large table
- Sections: "Closed Transactions", "Open Trades", "Working Orders"
- Trade columns: Ticket, Open Time, Type, Size, Item, Price, S/L, T/P, Close Time, Price, Commission, Taxes, Swap, Profit
- Date format: YYYY.MM.DD HH:MM or YYYY.MM.DD HH:MM:SS
- Types to process: "buy", "sell" (skip "balance", etc.)

## Key Design Decision
Each MT4 row = 1 complete trade -> split into 2 tradesData entries:
- Opening execution (B or SS): fees=0, grossProceeds=0
- Closing execution (S or BC): carries all fees + profit as grossProceeds
