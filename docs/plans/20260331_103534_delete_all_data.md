# Plan: Delete All Imported Data Feature

## Goal
Add a "Delete All Data" button to the Imports page that deletes all user data with a single click.

## Implementation

### 1. Backend utility function (`src/utils/trades.js`)
- Add `useDeleteAllData()` that queries and destroys all records from:
  - trades, excursions, playbooks, cashJournals, diaries, screenshots, satisfactions, tags, notes, dailyInfos, scenarios
- Uses existing Parse Query + `.destroy()` pattern
- Scoped to current user via ACL (Parse handles this automatically)

### 2. UI changes (`src/views/Imports.vue`)
- Add a "Delete All Data" button (red/danger style) below the imports table
- Use a Bootstrap modal for double confirmation (not a simple popover)
- User must type "DELETE" to confirm
- On success, refresh imports list and redirect to dashboard

### 3. Wire deletion in popover handler (`src/utils/utils.js`)
- Not needed - we use a modal + direct function call instead of the popover pattern

## Collections to delete
trades, excursions, playbooks, cashJournals, diaries, screenshots, satisfactions, tags, notes, dailyInfos, scenarios
